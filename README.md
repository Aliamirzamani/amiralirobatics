# امیرعلی رباتیک

وب‌اپ فارسی و راست‌به‌چپ آموزش رباتیک، ساخته‌شده با HTML، CSS و JavaScript بدون وابستگی نصب‌شونده.

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا در پوشهٔ پروژه دستور زیر را اجرا کنید و نشانی `http://localhost:8000` را باز کنید:

```sh
python -m http.server 8000
```

## انتشار با GitHub Pages

در تنظیمات مخزن به `Settings → Pages` بروید. در بخش `Build and deployment` گزینهٔ `Deploy from a branch` را انتخاب کنید، شاخهٔ `main` و پوشهٔ `/(root)` را تعیین کنید و `Save` را بزنید. پس از پایان انتشار، نشانی سایت در همان صفحه نمایش داده می‌شود.

## پنل مدیریت امن (Cloudflare Pages)

GitHub Pages فقط فایل‌های ثابت را میزبانی می‌کند و API ورود مدیر در آن اجرا نمی‌شود. پوشهٔ `functions/` شامل API ورود سروری است؛ برای فعال‌کردنش باید مخزن را به Cloudflare Pages متصل کنی و خروجی سایت را از ریشهٔ مخزن منتشر کنی (بدون دستور build).

در Cloudflare Dashboard، پروژهٔ Pages را باز کن و از `Settings → Variables and Secrets` این مقادیر را فقط در تنظیمات سرور وارد کن:

- `ADMIN_PHONE`: شمارهٔ ورود مدیر.
- `ADMIN_PASSWORD`: رمز تازه و قوی با حداقل ۱۶ نویسه؛ به‌صورت Secret ذخیره شود.
- `ADMIN_SESSION_SECRET`: راز تصادفیِ بلند با حداقل ۳۲ نویسه؛ به‌صورت Secret ذخیره شود.

بعد از افزودن Secretها دوباره Deploy کن و صفحهٔ `/admin.html` را باز کن. رمز قبلی را به‌دلیل افشاشدن در گفتگو استفاده نکن. برای کاهش تلاش‌های حدس رمز، روی مسیر `/api/admin/login` در Cloudflare نیز محدودیت نرخ درخواست فعال کن. این نسخه ورود را امن می‌کند، اما مدیریت واقعی سفارش‌ها و هنرجوها تا زمان اتصال APIهای آن‌ها و پایگاه داده فعال نیست.

## امکانات و محدودیت‌ها

- آزمون شش‌سؤالی، پیشنهاد پلن آموزشی، دوره‌ها و ماموریت‌های آموزشی.
- صفحهٔ ورود مدیر به API امن Cloudflare Pages متصل است؛ داشبورد، سفارش‌ها و حساب هنرجوها تا اتصال پایگاه داده نمایشی هستند.
- ثبت‌نام، فعال‌سازی پلن، سبد خرید، بارگذاری فیش و گزارش PDF فعلاً نمایشی هستند؛ حساب واقعی، پرداخت، ارسال فایل یا تولید PDF انجام نمی‌شود.
- نام و شمارهٔ واردشده فقط در حافظهٔ صفحه نگه‌داری می‌شوند و به سرور ارسال نمی‌شوند.
- فونت Vazirmatn از Google Fonts دریافت می‌شود؛ در حالت آفلاین فونت جایگزین استفاده می‌شود.

فایل‌های اصلی کاربر بدون تغییر عملکرد حفظ شده‌اند؛ فقط نام فایل HTML و CSS برای ورود استاندارد سایت هماهنگ شده است.
