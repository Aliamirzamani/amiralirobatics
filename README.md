# امیرعلی رباتیک

وب‌اپ فارسی و راست‌به‌چپ آموزش رباتیک، ساخته‌شده با HTML، CSS و JavaScript بدون وابستگی نصب‌شونده.

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا در پوشهٔ پروژه دستور زیر را اجرا کنید و نشانی `http://localhost:8000` را باز کنید:

```sh
python -m http.server 8000
```

## انتشار با GitHub Pages

در تنظیمات مخزن به `Settings → Pages` بروید. در بخش `Build and deployment` گزینهٔ `Deploy from a branch` را انتخاب کنید، شاخهٔ `main` و پوشهٔ `/(root)` را تعیین کنید و `Save` را بزنید. پس از پایان انتشار، نشانی سایت در همان صفحه نمایش داده می‌شود.

## امکانات و محدودیت‌ها

- آزمون شش‌سؤالی، پیشنهاد پلن آموزشی، دوره‌ها و ماموریت‌های آموزشی.
- صفحات دوره‌ها، والدین و فروشگاه با داده‌های نمایشی.
- ثبت‌نام، فعال‌سازی پلن، سبد خرید، بارگذاری فیش و گزارش PDF فعلاً نمایشی هستند؛ حساب واقعی، پرداخت، ارسال فایل یا تولید PDF انجام نمی‌شود.
- نام و شمارهٔ واردشده فقط در حافظهٔ صفحه نگه‌داری می‌شوند و به سرور ارسال نمی‌شوند.
- فونت Vazirmatn از Google Fonts دریافت می‌شود؛ در حالت آفلاین فونت جایگزین استفاده می‌شود.

فایل‌های اصلی کاربر بدون تغییر عملکرد حفظ شده‌اند؛ فقط نام فایل HTML و CSS برای ورود استاندارد سایت هماهنگ شده است.
